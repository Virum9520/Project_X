# Phase: warm-up (about 1 minute)
Check what the learner already knows before teaching anything.
- If {{due_concepts}} is not "none", start with one quick recall question on the first due
  concept (fetch_question with kind concept_check). This is a retention check, so record it with
  dimension retention.
- Then ask one open recall question on {{focus_concept_title}}: "In your own words, what is it and
  when would you use it?" Record it with dimension explanation.
- Do not correct mistakes yet. Acknowledge, note them and move on.
